## 📌 Executive Summary & Key KPIs

By analyzing **54.38K+ transactions** and **$158M in Net Revenue**, this repository maps out critical drivers across demographics, payment options, and geographic regions.

<div align="center">

| Core Metric | Value | Strategic Context |
| :--- | :---: | :--- |
| 💰 **Total Net Revenue** | **$158.00M** | Net earnings post-discounts and refunds |
| 📈 **Gross Profit** | **$165.54M** | Earnings prior to operating expenditures |
| 📊 **Profit Margin** | **4.61%** | Core channel profitability indicator |
| 🧾 **Total Orders** | **54.39K** | Total completed order transactions |
| 🛍️ **Average Order Value (AOV)** | **$2.91K** | Gross expenditure generated per basket |

## 🎯 Key Business Insights

> #### 1️⃣ Category Dominance
> **Electronics** and **Clothing** account for over **50%** of total net revenue, serving as the primary baseline for product cross-selling strategies.

> #### 2️⃣ Core Demographic
> The **25–48 age group** drives the majority of purchase volume, representing the highest customer lifetime value (LTV) cohort.

> #### 3️⃣ Discount Leakage
> Credit Card and Debit Card payments absorb the highest total discount volumes, directly impacting net margin health.

> #### 4️⃣ Geographic Growth Markets
> High-volume regional cities — including **Srinagar, Dehradun, and Varanasi** — exhibit strong Average Order Values (AOV), signaling high-potential regional expansion hubs.
